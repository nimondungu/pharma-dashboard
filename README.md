# 💊 PharmaTrack EA

PharmaTrack EA — A personal frontend project simulating real-world pharma
stock intelligence across East Africa. Built in vanilla HTML5, CSS3 &
JavaScript — covers expiry tracking, inventory flow & KES/USD portfolio
valuation. Features reactive KPIs, drill-down modals, cross-country
comparisons, email alerts, 5 themes & mobile-ready.

## 🔗 Live Demo
[View Dashboard](https://nimondungu.github.io/pharma-dashboard/PharmaTrack_Dashboard.html)

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript
- EmailJS

## 📊 Features
- Expiry tracking across Kenya, Uganda & Tanzania
- Multi-select filters with chip UI
- Reactive KPI cards with drill-down modals
- Cross-country drug comparisons
- KES/USD portfolio valuation
- Email alerts via EmailJS
- 5 switchable UI themes
- Fully mobile responsive
